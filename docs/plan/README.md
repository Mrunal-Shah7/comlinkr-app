# Plans

What will change and why, written before building. One file per plan, named `NN-short-name.md` (numbered in
order), and listed with its status in [../README.md](../README.md).

Each plan starts with its status (Draft, Agreed, Building, Done) and its triage line, then: the problem, what will
change, what will not, the questions for the owner and their answers, and how it will be checked (unit or e2e
tests, and the checklist rows to walk on the phone). Decisions made while building go in a "Decided while
building" section at the end.
